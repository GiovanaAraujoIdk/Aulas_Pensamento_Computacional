# Aulas - Algoritmo e Pensamento Computacional 💻✨

Bem-vindo(a) ao meu repositório de **Atividades em C** desenvolvidas durante as aulas de Pensamento Computacional na faculdade.  
Aqui estão reunidos os **exercícios práticos** e **atividades de sala** que ajudam a consolidar a lógica de programação e os conceitos fundamentais da linguagem C.

## 📂 Estrutura
- **Exercícios**: Pequenos programas em C para treinar lógica e sintaxe (`exer1.c`, `exer2.c`, etc.)
- **Aulas**: Exemplos e códigos trabalhados em sala (`Aula_3`, `Aula_4`, etc.)
- **Testes práticos**: Arquivos auxiliares como `main_perimetro.c` e outros exemplos de aplicação.

## 🎯 Objetivo
Este repositório serve como registro da minha evolução em programação com C e como material de apoio para colegas que também estão aprendendo.  
O foco é **praticar lógica computacional** e **ganhar fluência na linguagem C** antes de avançar para projetos maiores.
